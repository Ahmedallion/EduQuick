# Downgrading EduQuick

If a recent update introduces unexpected issues or breaks certain features, you can revert to an earlier stable version of EduQuick.

---

## How to Downgrade

Follow these steps to use a previous version:

### 1. Access the release files

Go to the EduQuick releases page on GitHub:

[EduQuick Releases](https://github.com/Ahmedallion/EduQuick/releases){: .btn .btn-purple }

### 2. Choose a previous version

Look for one of the following files in the release assets:

- `eduquick-import.html`
- `eduquick-bookmarklet.js`

Both files can be used to install EduQuick. Follow the normal installation process as described in the guide below:

[Installation Guide](../installation){: .btn .btn-purple }

### 3. Replace your current bookmarklet

Remove your existing EduQuick bookmark, then add the file you downloaded using your preferred method above.

---

> ⚠️ Note: Only downgrade if necessary. Older versions may not include the latest fixes or features.
